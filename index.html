PAPER SUMMARY · MARKET MICROSTRUCTURE

《Bias in the effective bid-ask spread》论文总结

作者：Björn Hagströmer　|　期刊：Journal of Financial Economics 142（2021）314–337
中文标题：有效买卖价差中的偏差　|　基于本地双语 PDF 整理
一句话概括： 传统以买卖盘中点（midpoint）为基本价值代理来计算有效买卖价差，会在离散报价且交易者具有弹性流动性需求的市场中系统性高估真实交易成本；这种偏差还会改变流动性排序、交易场所比较和交易绩效评价。

一、论文在讲什么

有效买卖价差本来用于衡量一笔立即成交的交易相对于证券真实基本价值所支付的成本。由于真实基本价值无法直接观察，实务和学术研究通常使用最优买价与最优卖价的平均值，也就是买卖盘中点，作为基本价值的替代。

论文指出，这种做法隐含了一个容易被忽视的假设：真实基本价值位于买价和卖价的正中间。但在实际市场中，价格是离散的，真实价值是连续的，做市商也未必能围绕真实价值对称报价。因此，买方主动成交和卖方主动成交的真实成本可能不同。

如果交易者能够识别这种不对称，并主动选择交易成本更低的一侧，那么成交方向就不再是随机的。此时，成交样本会系统性偏向“便宜的一侧”，而 midpoint 计算仍把买卖价差看作对称成本，最终导致有效价差被高估。

二、核心观点

核心观点：“中点有效价差”不是一个普遍无偏的真实交易成本估计量。只要市场存在离散 tick、订单簿不对称，以及交易者会对交易成本差异作出反应，midpoint 方法就会产生正向偏差。

论文强调的不是有效价差概念错误，而是其基本价值代理变量选择得过于粗糙。主要结论可以归纳为：

  • 中点有效价差平均高估真实有效价差。
  • 偏差在低价股、相对 tick size 较大的股票中更严重。
  • 偏差在不同股票、交易场所和投资者群体之间并不相同。
  • 因此，基于 midpoint 的流动性排名和交易绩效比较可能产生错误结论。
  • 使用订单簿深度和不平衡信息构造 weighted midpoint 或 micro-price，可以缓解这一问题。

三、直观例子：为什么 midpoint 会高估

论文给出一个例子：某股票真实基本价值为 25.0025 美元，市场允许的最近报价为买价 25.00 美元和卖价 25.01 美元。

交易方向成交价格相对真实价值的单边距离有效价差
卖方主动，以 bid 成交25.000.25 美分0.50 美分
买方主动，以 ask 成交25.010.75 美分1.50 美分
midpoint 方法25.005假设两侧对称1.00 美分

真实成本在买卖两侧是不对称的。如果交易者知道卖方主动成交一侧更便宜，就会有更多订单在 bid 侧成交。平均下来，真实有效价差低于 midpoint 方法计算出的 1 美分，但 midpoint 估计并不会跟随这种订单流偏移。

四、作者如何进行理论论证

1. 定义真实有效价差和估计有效价差

论文将真实有效价差定义为：

S = 2D(P − X)

其中，P 是成交价，X 是交易时点的真实基本价值，D 是交易方向：买方发起为 +1，卖方发起为 −1。

实际研究中无法观察 X，只能使用代理变量 X̃，于是估计有效价差为：

S̃ = 2D(P − X̃)

2. 推导无偏条件

估计误差的期望为：

E[S̃ − S] = 2E[D(X − X̃)]

因此，有效价差估计量无偏的充要条件是：

交易方向 D 与基本价值估计误差 (X − X̃) 不相关

对 midpoint 方法而言，如果投资者不知道真实价值偏离 midpoint 的方向，或者订单流完全不受交易成本影响，这一条件可能成立。但只要交易者能够识别偏离方向，并据此调整买卖方向，相关性就会出现，估计量就会有偏。

3. 为什么偏差是正的

当真实价值更靠近 bid 时，卖方主动成交成本更低，卖方订单相对更多；当真实价值更靠近 ask 时，买方主动成交成本更低，买方订单相对更多。也就是说，交易流会更多地出现在价差的窄端。

midpoint 方法却默认买卖两端围绕中点对称，不能识别真实价值的位置和订单流的选择性。于是，计算得到的平均有效价差高于交易者实际支付的平均成本。

五、作者提出的替代方法

1. 加权中点（Weighted Midpoint）

加权中点利用最优买价和卖价上的订单深度：

X̃wm = (PBQA + PAQB) / (QA + QB)

其中，PB 和 PA 分别是最优买价和最优卖价，QB 和 QA 是两侧的报价深度。

它的直觉是：订单簿深度不平衡包含基本价值信息。加权中点不是简单取价格平均，而是让订单较薄的一侧对估计价格产生更大权重，从而使估计值能够偏向更可能的真实价值。

2. 微观价格（Micro-price）

micro-price 在订单簿不平衡的基础上，进一步考虑未来买卖盘中点变化的概率和幅度。它可以理解为对当前 midpoint 的预测性调整，目标是更准确地刻画短期有效价格。

论文认为，从理论上看 micro-price 更有吸引力，因为它被构造成鞅；但 weighted midpoint 更容易实时计算，且只需要常见的盘口价格和深度数据。

六、实证设计与主要结果

1. 数据

  • 2015年12月7日至11日的 S&P 500 成分股交易和报价数据。
  • Nasdaq 提供的带有 HFT 标识的美国股票交易数据，用于区分高频交易者与非高频交易者。
  • 1996年至2015年 NYSE 普通股的长期样本，用于研究偏差的时间变化和市值分组差异。

2. 有效价差大小

3. 偏差的横截面和时间特征

  • 低价股偏差显著更大。S&P 500 中价格低于 15 美元的股票，按 weighted midpoint 衡量的平均偏差约为 52%；按 micro-price 衡量可达 97%。
  • 1996年至2015年的长期样本显示，偏差在 2001 年附近接近于零，之后逐渐上升，2009 年后总体约稳定在 17% 左右。
  • 2009年至2015年期间，大盘股、中盘股、小盘股的平均偏差约分别为 18%、12% 和 7%。
  • 交易场所之间也有差异：例如 NYSE 平均偏差约 16%，Nasdaq BX 约 7%。

4. 交易方向与价值偏离确实相关

作者用回归检验交易方向与“真实基本价值相对于 midpoint 的偏离”之间的关系，发现二者存在显著正相关。论文报告的回归斜率约为 0.44，且在统计上显著，直接拒绝了 midpoint 有效价差无偏所需要的条件。

七、为什么这个偏差具有经济意义

1. 会改变流动性排序

偏差随着相对 tick size 变化，而相对 tick size 与股价密切相关。若直接用 midpoint，有些低价股会被错误地判断为流动性更差。

2. 会改变交易场所排名

不同交易场所的订单簿结构和交易机制不同，偏差程度也不同。论文发现，midpoint 方法给出的交易场所排名与基准估计一致的股票交易日仅约 39%。这意味着交易所执行质量或最佳执行比较可能被错误排序。

3. 会扭曲 HFT 与非 HFT 的绩效比较

在 Nasdaq HFT 样本中，使用 weighted midpoint 时，提供流动性的 HFT 获得的有效价差比非 HFT 高约 15%；但使用 midpoint 时，结论反而变成 HFT 获得的收益比非 HFT 低约 3%。同一组数据因为估计量不同而得到相反结论，说明该测量偏差足以影响研究推断。

4. 会损害流动性择时

作者模拟了只在基本价值跟踪方式上不同的流动性择时策略。基于 weighted midpoint 进行择时的投资者，不仅估计出的有效价差更低，基于成交价格计算的 execution shortfall 也更低。说明只盯 midpoint 的交易者可能会在不利时点支付过高的流动性成本。

八、对量化交易和交易成本分析的启示

  1. TCA 不应只使用 midpoint。 对高频策略、主动成交和盘口择时，应至少加入订单簿深度和买卖盘不平衡信息。
  2. 低价股尤其需要修正。 固定 tick size 下，股价越低，相对 tick size 越大，midpoint 偏差通常越严重。
  3. 交易所比较要使用统一基本价值。 跨交易场所比较时，应使用 NBBO 或其他跨市场统一的有效价格，而不是分别使用各交易所自己的 midpoint。
  4. 回测中的成交成本模型可能偏乐观或偏悲观。 若用 midpoint 有效价差校准交易成本，可能错误估计不同股票、交易所或投资者群体的真实成本。
  5. 可实时计算。 weighted midpoint 只需最优买卖价和两侧深度；micro-price 的复杂部分可以用历史数据提前估计，盘中只做状态映射。

九、论文的边界和需要注意的地方

  • 真实基本价值本身不可观测，因此 weighted midpoint 和 micro-price 也不是“真值”，而是更合理的代理变量。
  • 这些替代方法隐含假设订单簿包含主要相关信息；若加入更深层盘口、其他交易系统、相关证券或指数信息，估计可能进一步改进。
  • 论文的核心偏差结论针对有效价差测度，并不意味着 midpoint 在所有应用中都存在同样问题。作者特别指出，在收益率或实际波动率等其他应用中，midpoint 与基本价值的偏离未必同样重要。
  • 论文证明的是测量方法存在系统性偏差，不是说所有交易者都能稳定赚取该偏差，也不是说 weighted midpoint 或 micro-price 能保证降低所有策略的实际交易成本。

十、最终总结

论文的完整论证链条是： 价格离散 → 买卖两侧真实成本不对称 → 交易者根据成本差异调整订单方向 → 交易方向与 midpoint 误差相关 → midpoint 有效价差系统性高估 → 流动性排序、交易场所评价和交易绩效比较可能被扭曲。

因此，作者建议在有效价差及交易成本研究中，用 weighted midpoint 或 micro-price 等更能反映订单簿信息的基本价值代理替代简单 midpoint。对量化交易而言，最直接的实践结论是：盘口不平衡不仅是价格方向信号，也是交易成本测量和流动性择时的重要信息。
